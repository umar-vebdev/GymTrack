## Точный следующий шаг

1. Создать Value Object `CompanyId` в `app/Shared/Domain`.
2. Создать интерфейс `Clock` и его реализацию `SystemClock` в `app/Shared/Domain` и `app/Shared/Infrastructure` соответственно, привязать в `AppServiceProvider`.
3. Создать базовый интерфейс (или класс) `DomainEvent` в `app/Shared/Domain`.
4. Написать модульные тесты.
5. Запустить все проверки (lint, analyse, deps, test).
