## Точный следующий шаг

1. Настроить префикс `/api/v1` для API маршрутов (по ТЗ все маршруты должны быть версионированы, либо в `bootstrap/app.php` либо в самом `routes/api.php` создать группу).
2. Настроить обработчик исключений (`bootstrap/app.php` -> `withExceptions`) для приведения всех ошибок к формату: `{"error": {"code": "...", "message": "..."}}`.
   - Ошибки валидации -> 422.
   - Ошибки маршрутизации/ModelNotFound -> 404.
   - Доменные исключения (InvalidArgumentException и др.) -> 400.
   - Остальные -> 500.
3. Написать Feature-тесты на 404, 422 и 500.
4. Проверить `composer test`.
