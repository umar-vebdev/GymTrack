## Точный следующий шаг

1. Создать `.github/workflows/ci.yml`.
2. Настроить запуск CI при `push` и `pull_request` на ветку `main`.
3. Конвейер должен поднимать сервисы PostgreSQL и Redis (через `services` в GitHub Actions).
4. Шаги: checkout, setup-php (PHP 8.4), `composer install`, скопировать `.env`, сгенерировать ключ, запустить `composer lint -- --test`, `composer analyse`, `composer deps`, `composer test`.
5. Сделать коммит и запустить конвейер.
