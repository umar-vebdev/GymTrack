- Настроен глобальный обработчик исключений (`bootstrap/app.php`) для приведения всех ошибок API к единому формату. Эндпоинты API перенесены под префикс `/api/v1/`. Написаны и запущены Feature-тесты для форматов 404, 422 и 400 (T0-11 выполнена).

## Точный следующий шаг

1. Проверить, установлен ли пакет `laravel/sanctum` (он обычно идёт по умолчанию в Laravel 11 при запуске `install:api`).
2. Опубликовать миграции Sanctum (если ещё не).
3. Создать временный защищённый маршрут в `routes/api.php` (например, `Route::middleware('auth:sanctum')->get('/user', ...)`).
4. Написать Feature-тест (`tests/Feature/SanctumAuthTest.php`), который проверяет, что обращение к этому маршруту без токена возвращает 401 Unauthorized (в новом едином JSON-формате, если возможно, или стандартном).
5. Прогнать все тесты.
